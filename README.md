# Cifron AI

Интеллектуальная карта движения денег для AML-аналитика. Cifron AI локально в браузере строит направленный граф переводов до четырёх уровней, назначает предполагаемые роли счетам и ранжирует узлы для ручной проверки.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) и нажмите «Загрузить демо-сценарий» либо загрузите UTF-8 CSV с колонками `transaction_id,timestamp,sender,receiver,amount,currency,comment`.

Проверки проекта:

```bash
npm run lint
npx tsc --noEmit
npm run build
```

Это MVP без базы данных, авторизации и подключения OpenAI API. Обработка CSV выполняется локально в браузере. Risk score является объяснимой эвристикой и помогает приоритизировать ручную проверку.

> Cifron AI — вспомогательный аналитический инструмент. Результаты не подтверждают факт нарушения и требуют проверки AML-специалистом.
