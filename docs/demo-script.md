# Cifron AI Demo Script

## Пятиминутный сценарий

1. Показать папку `data/` с тремя Parquet и запустить `npm run pipeline`.
2. Открыть `outputs/` и показать три CSV, число строк `nodes_roles.csv` и первые строки `top_nodes.csv`.
3. Запустить UI командой `npm run dev` и загрузить demo-сценарий, пояснив, что это демонстрационный набор, а не полный датасет ТЗ.
4. Найти через поиск 2–3 `gid`, выбрать узлы на графе и показать направление связей, глубину, роль, score и evidence из pipeline-выгрузки при наличии соответствующего импорта.
5. Показать AI-анализ выбранного узла как дополнительный слой: он не меняет базовую роль или priority и требует проверки AML-аналитиком.

## Что проговорить

- Базовый расчёт локальный, воспроизводимый и не требует внешнего API.
- Роли основаны на наблюдаемых переводах и формальных percentile-порогах.
- Данные содержат только исходящие переводы до четырёх колен; seed имеют неполные наблюдаемые входящие.
- Порог ниже 5000 KZT не виден, а depth=4 без исходящих не доказывает terminal.
- Нет ground truth ролей и атрибутов клиентов, поэтому результаты являются гипотезами для ручной проверки.
